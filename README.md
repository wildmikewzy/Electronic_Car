# 东南大学电赛校赛初体验 - F题智能搬运小车

## 🏆 赛题回顾与最终战绩

本届校赛 F 题要求设计并制作一辆能够自主导航的智能搬运小车。小车需要在 150cm × 150cm 的白色场地内，依靠特设的黑色引导线进行路径规划，并具备图像获取与处理、自动抓取/放置标准乒乓球（改制物体）以及接收击掌声音启动等功能。小车需要在指定的时间内，自主行驶并完成特定子区域内物体的精准搬运，最终将其送入中心处的圆柱形置物桶 M 中 [cite: 4, 23, 24, 27]。

在这次比赛中，我们团队分工明确，成功完赛并荣获 **校级三等奖 🥉**！

作为团队中的主要开发者之一，我在此项目中主要负责**车体控制部分的底层及核心应用层代码**。
* **核心控制板**：英飞凌 AURIX™ TC377 单片机
* **开发环境**：AURIX Development Studio
* **开发库函数** 逐飞TC377库

## 📐 核心任务拆解与状态机设计

本项目的控制应用层采用**时间片轮询结合分步状态机（Switch-Case**的架构。底层由 5ms 的定时器（PIT）提供高精度时基，并以 20ms 为周期驱动各任务状态机。

在路径规划上，系统采取了 **“高精度惯导筑基，多传感器配合”** 的策略：
* **无黑线区域/大范围转移**：闭环由 逐飞IMU660RA 解算出的航向环（Yaw）与磁编码器记录的距离环，实现高确定性的盲跑。
* **有黑线区域**：当惯导引导小车切入黑线附近时，状态机切换至 **5路灰度传感器巡线模式**。

由于比赛时间有限，团队采取了稳中求进的策略，最终完成了全部基础题以及发挥题前两问的开发。以下为核心任务的执行逻辑拆解：

---

### 1. 基础任务拆解 (`task1_logic` ~ `task3_logic`)

基础题不放置任何乒乓球，主要考核小车的精确定位与轨迹追踪能力。

* **基本要求 (1)：A $\rightarrow$ B $\rightarrow$ A 往返冲刺**
  * **A $\rightarrow$ B**：纯惯导模式，锁死 `Yaw = 0.0f` 直线前冲 1.0 米。
  * **B 点折返**：利用航向环和距离环实施多段式分步大角度原地调头，分阶段锁死 `Yaw = 90.0f` 中继点，最终锁定 `Yaw = 180.0f` 反向对准 A 点。
  * **B $\rightarrow$ A**：盲跑回程一小段后，状态机主动切入灰度传感器巡线模式（`gray_track_PID_realize`），利用黑线精准矫正回程累积误差，最终回 A 点停车并触发声光提示。

* **基本要求 (2)：A $\rightarrow$ D $\rightarrow$ C $\rightarrow$ B $\rightarrow$ A 矩形环线**
  * **A $\rightarrow$ D**：依靠惯导纵向推行到达 D 点。
  * **D $\rightarrow$ C**：通过航向环原地旋转 90 度（锁死 `Yaw = 90.0f`）对准黑线，随后无缝切入灰度巡线通过 DC 引导线区域，检测到丢线且里程满足时判定到达 C 点。
  * **C $\rightarrow$ B $\rightarrow$ A**：在 C 点原地旋转至 `Yaw = 180.0f`，利用纯惯导盲跑直线跨越无引导线区冲向 B 点；在 B 点原地旋转至 `Yaw = 270.0f` 转向 A 点，同样盲跑一小段后，切入 BA 引导线巡线，精准平稳地杀回起点 A 停车。

* **基本要求 (3)：绕置物桶环线（b $\rightarrow$ c $\rightarrow$ d $\rightarrow$ a 区域巡航）**
  * 赛题规定在非引导线路段不得触碰引导线和置物桶，采取圆轨迹方案路径的规划和设计相比于正方形路径会困难一些。经过了讨论，我们将“绕桶一圈”精细化拆解为**多段式“折线外廓巡航”状态机**，即走多边折现路径。
  * 依次经历 4 次精密的原地 90 度直角转弯（航向锁死序列：`270°` $\rightarrow$ `180°` $\rightarrow$ `90°` $\rightarrow$ `0°`），中间配合编码器距离闭环（冲刺距离从 0.65m 到 0.3m 逐段递减向心收缩），使小车过 b、c、d、a 区域。
  * 绕桶结束后，通过 `294°` 的特殊中角切回 C 点，最终再次利用 CD、和一段惯性导航返回 A 点。

### 2. 发挥任务拆解与赛场复盘 (`task4_logic` ~ `task5_logic`)

发挥题核心在于引入视觉识别（乒乓球与置物桶标签均为 0）和机械臂/电磁铁抓搬运结构。

* **发挥要求 (1)：自选位置抓球放桶**
  * **惯导冲刺寻球**：初始化舵机与电磁铁后，依靠航向环直线高速盲跑 0.20 米快速切入球体盲区。若中途摄像头捕获目标（`vision.y > 30`），则立刻切换为视觉修正。
  * **视觉纵向对准（仅仅通过视觉修正y）**：切换至视觉 $Y$ 轴单闭环逼近模式（`image_control_update`），实施“远距离快跑、近距离慢速”的非线性控速。
  * **抓取与冲桶**：待$Y$ 轴对准稳定后刹车，下放机械臂，开启电磁铁吸球并带球抬高。随后，小车再次利用惯导前冲 0.22 米，并再次切入视觉 $Y$ 轴单闭环精确逼近置物桶 M，卸载小球。

* **发挥要求 (2)：A点出发抓取 c 区域球放桶（附赛场复盘）**
  * **全流程逻辑**：小车从 A 点出发，首先通过纯惯导模式直线挺进 0.80 米，原地右转 90 度切入 c 区域。随后升起机械臂并依靠惯导盲跑 0.40 米接近小球。
  * **双轴视觉高精度对准**：在此阶段，方案引入**两段式视觉修正算法**——首先通过 $Y$ 轴单闭环把车开到小球面前，随后状态机跳转至 `case 35`（横向 X 轴 PID 原地精调），强制锁定纵向速度，通过横向微分阻尼克服自转静摩擦力，使车身完美、正对地锁死在小球中心线（X轴死区）上，成功实现了高难度的精准吸球。
  * **遗憾复盘（偏差产生原因）**：由于 c 区域中心点距离中央置物桶 M 的物理距离极短，吸球完毕带球抬高后，程序设计为了**纯开环控制逻辑**：即原地开环盲转 90 度（锁 `Yaw = 180.0f`）后直接尝试放下小球。然而在实际比赛测试中，由于机械臂和吸球动作带来的物理震动，以及前期视觉微调时车体留下的微小微调姿态，使得**开环转向的初始基准发生了偏转**。开环自转 90 度后，车头机械臂探出的位置产生了数厘米的几何偏差，导致小球最终遗憾地擦着桶边落在了外面，在此项任务中仅获得了一半的分数。

### 🎛 任务管理：五向开关菜单系统
为了在赛场上面对裁判的不同项目抽检时能够快速响应，程序在主循环中实现了一个基于**五向开关控制的菜单**。
通过上下拨动开关实时移动光标、按下确定键直接修改 `current_running_task` 的状态。在任务切换或触发 `TURN_OFF` 状态时，系统会调用 `reset_task_variables()` 函数，强行将状态机 `sub_step` 归零、清空编码器里程、并**彻底重置航向环及视觉 PID 结构体中的残余变量（如积分项、last_err）**，从硬件和软件底层双重避免了由于任务无缝切换导致的电机突冲、乱转异动，保障了赛场调试的任务切换的快速便捷。

## 💡 心得体会与 2027 年国赛展望

### 1. 赛后复盘与心得体会

这次电赛校赛虽然留下了发挥题第二问放球跑偏的遗憾，但整个备战和比赛的过程让我们团队收获了远比奖牌更宝贵的实战经验。作为负责车体控制的组员，我有以下几点深刻的体会：

* **底层稳如泰山，上层才能健壮**：比赛前期我花大精力把 IMU660RA 陀螺仪的姿态解算调通，并基于磁编码器建立了速度环、航向环和距离环。事实证明这个决定无比正确。基础题巡线、绕桶的大范围转移，以及发挥题视觉捕捉前的盲跑冲刺，全部赖于这套扎实的惯导地基。如果底层电机控制不稳，上层的算法逻辑再漂亮也只是空中楼阁。
* **状态机设计需敬畏“资源复用”与“状态残留”**：在解决“视觉一看到桶就停”和“X轴原地自转过冲”的 Bug 时，我深刻意识到，在嵌入式多任务/多状态切换的环境下，每一个状态跳转都必须进行彻底的“资源清空”（如 `reset_task_variables()`）。没有软件层面的强力重置，PID 积分和稳定计数器的残留必然会引发系统的灵异异动。
* **从开环到闭环的跨越，决定了工程的上限**：发挥题第二问的失败，本质上是“前半段高精度视觉双轴闭环”与“末端放球纯开环”之间的矛盾。在硬件结构、地面摩擦力和震动等物理不确定性面前，开环逻辑脆弱不堪。这也让我真正理解了开环的不稳定性和全流程闭环的必要性。
